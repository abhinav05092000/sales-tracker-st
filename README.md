# sales-tracker-st
Sales Tracker

Project Overview

A lightweight sales tracker designed for ongoing transaction entry and
automatic daily, weekly, and monthly aggregation.

Office & Smart Devices

Objective

Structure transaction-level sales data

Calculate sales automatically

Generate daily, weekly, and monthly totals

Reduce bad entries with data validation

Keep raw data separate from summary calculations

Tools

Microsoft Excel / Google Sheets

SUMIFS, SUM, EDATE, WEEKDAY

Data Validation

Conditional Formatting

Charts

Workbook Structure

Date, Region, Salesperson, Product, Category, Quantity, Unit Price and
formula-driven Sales Amount.

Summary

KPI cards, daily total, weekly total, monthly total, monthly sales trend

Step-by-step guidance for data entry and manual verification.

Interview Questions

How would you design a spreadsheet so non-technical staff can enter
data safely?
Use clear input fields, dropdowns, protected formula columns,
instructions and a separate summary sheet.

What's the risk of mixing raw data and formulas on the same tab?
Users can overwrite formulas or introduce inconsistent edits. Separating
input and summary layers improves reliability and auditability.
